# Grove Git Client Implementation Plan

> For agentic workers: use subagent-driven-development for the independent Git service and requesting-code-review for review. The primary agent owns the desktop integration and interface.

**Goal:** Build a polished desktop Git client with real repository management, history, diffs, and Git actions.

**Architecture:** React and TypeScript renderer, context-isolated Electron preload, and a Node Git service using argument arrays. The browser preview runs an explicitly labeled interactive demo. Real Git access is desktop-only.

**Tech Stack:** Electron, React, TypeScript, Vite, Lucide, Node test runner, Playwright.

## Tasks

- [x] Git service: create `desktop/git.mjs` and `tests/git.test.mjs`. Write real temporary repository tests first for status, history, diff, stage, unstage, commit, branching, stashing, remote sync, and conflicts. Run `npm test` before and after implementation. Ensure no shell interpolation, path containment, serialized writes, and useful errors.
- [x] Desktop: create `desktop/main.mjs`, `desktop/preload.cjs`, and `scripts/dev.mjs`. Expose a single validated request function. Register repositories through the native picker, persist recent projects atomically, restrict navigation and IPC senders, and refresh on focus and repository file events. Verify actual Electron launch and bridge calls against disposable fixtures.
- [x] Interface: create `src/App.tsx`, `src/components/*`, `src/styles.css`, `src/demo.ts`, and `src/api.ts`. Build three resizable panes, local changes and commit composer, history graph, diffs, repository selector, and focused operation forms. Use `src/types.ts` for the shared data shapes. Verify staging, commit, history, dialogs, and responsive layouts through browser and native desktop interaction.
- [x] Advanced actions: wire branch, remote, stash, tag, merge/rebase, reset/revert/cherry-pick, conflict editor, and explicit command execution to the service. Require local UI confirmation for actions that lose work. Preserve input and show actual errors.
- [x] Review and delivery: review spec coverage and code quality; run `npm test`, `npm run build`, browser and native desktop interaction checks; inspect desktop and browser screenshots; package an unsigned macOS app and write startup instructions in `README.md`.

## Service contract

Export `GitService` from `desktop/git.mjs`; its `request(method, payload)` dispatches `root`, `snapshot`, `history`, `diff`, `commitDetails`, `action`, `readFile`, `writeFile`, `init`, and `clone`. Payload always supplies `path` for repository methods. `history` accepts `skip`, `limit`, and `search`; `diff` accepts `file`, `staged`, optional `commit`, and `full`; `commitDetails` accepts `hash`. Return shapes match `src/types.ts`. Actions return command output strings. Desktop adds `projects`, `open`, `forget`, and `pickDestination` methods.

## Acceptance

The app opens real projects, renders actual history and local changes, stages files, creates commits, and exposes the approved Git workflows. A fresh browser launch prominently identifies sample repositories as demo data. Empty, loading, failed, detached, conflicted, and no-upstream states remain usable. All repository-changing tests use temporary fixtures. Packaging is local and unsigned; publishing is outside this request.
